# DL Midterm 2026: Text-to-SVG Generation

This repository contains our training, experimentation, and inference code for the NYU Deep Learning Spring 2026 Kaggle competition on text-to-SVG generation.

## Repository Structure

- `data/` contains the provided dataset files
- `notebooks/` contains EDA and training experiment notebooks
- `training/` contains training scripts and configs
- `inference/` contains the final Kaggle inference notebook and submission pipeline

## Reproducibility

To reproduce the final submission:
1. Install dependencies from `requirements.txt`
2. Open `inference/kaggle_inference.ipynb`
3. Run all cells end to end
4. Generate `submission.csv`
